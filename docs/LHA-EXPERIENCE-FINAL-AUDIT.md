# LHA 2.0 — Full Website Premium Quality Gates

**Date:** October 19, 2026
**Purpose:** Preserve the user's explicit requirement that the COMPLETE Libya Hoops Academy website — every page, heading, button, icon, message, photo, mobile layout and account state — must feel simple, premium, and coherent. This document is an UNFINISHED audit checklist, not a claim that the work below is complete.

## Non-negotiable identity
- The UI palette is black, white and neutral grays only; the original brand logos and real player/product photography keep their faithful appearance and colors.
- Premium basketball editorial direction. Distinct experiences for academy programs, online training, apparel and accessories, yet all connected by one navigation, type scale, and component system.
- English and Arabic must both be **edited**, not machine-like mirrors. Arabic spelling of 'ليبيا هوبس أكاديمي', terminology, price units, dates, form hints and empty states all need line-by-line review.
- Every interactive element uses consistent accessible SVG icon language, clear names, at least 44px target sizes, hover/focus states, proper contrast, loading feedback, usable RTL and LTR.
- Hero sections use authentic, authorized media; no made-up athlete, club, tournament, video, coach, or placeholder content. Compress real media without ruining sharpness.
- Verify mobile widths 320, 375, 390, 430, tablet 768, laptop 1024, and 1440px desktop, bilingual, keyboard and reduced motion. No overlapping headers, cropped main titles, horizontal overflow, broken filters or hidden CTAs.
- Visitors must never be misled by payment, fulfillment, inventory or shipment claims.

## Route-by-route acceptance queue (INCOMPLETE until separately tested)
1. Global site shell: announcement/header/mobile menu/search/language/currency/cart/account/actions, navigation route changes, icon alignment, focus, footer/legal/newsletter.
2. Home: hero video/poster quality, real BAL/non-game training media where authorized, typography, in-person/digital/store pathway contrast, apparel *more prominent* than generic gear, accessories distinctly framed, merchandising actually in stock, primary CTA.
3. Shop and category pages (clothing, accessories and each actual subcategory): grid, product photos, filters, in-stock/out-of-stock status, currency, bilingual descriptions, gallery and touch support.
4. Product detail: variant size/color actual stock, correct pricing/units, honest preorder/deposit timing and bank-transfer availability only when operational, wishlists, compare, bag and order pathways.
5. In-person programs: quality images, age/level expectations, accurate descriptions/pricing/schedules, no fabricated enrollment availability.
6. Online training index and each detail: exact monthly/multi-month/full plan values, bilingual real curriculum, honest coming-soon previews, rights and secure access/entitlement verification.
7. Cart/checkout/order confirmation: valid country shipping, COD-only physical eligible products, secure payment confirmation, idempotent operations, accessible address collection, no false paid/shipped status.
8. Order lookup, order details, account/order history: PII protection, verified email ownership, order number, real Center Vision status, no fictitious carrier progress.
9. Coaches, events, league/academy editorial: verified active staff, legitimate event dates and photos, no old 2026 events marketed as upcoming.
10. About, contact, help, FAQ, returns/shipping/privacy/terms, 404/offline/error screens: all copy reviewed, consistent design and real links, working forms, no stale or generic placeholder claims.
